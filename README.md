
# Sports Performance: A Visual Exploration of NBA Players

## CodeAlpha Internship — Task 2: Data Visualization

## About the Project

This project explores NBA player statistics from the 2023–2024 season using Python data visualization libraries.

The goal is to understand player scoring, assists, rebounds, shooting efficiency, and relationships between performance statistics through clear charts.

## Objectives

- Identify the top 10 NBA players by points.
- Explore the distribution of player scoring.
- Compare points with assists and rebounds.
- Compare average player scoring across teams.
- Examine field-goal and three-point shooting percentages.
- Explore relationships between basketball statistics.
- Understand the spread of scoring performance.

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Visualizations

1. Top 10 NBA Players by Points
2. Distribution of Points Among Players
3. Relationship Between Assists and Points
4. Relationship Between Rebounds and Points
5. Team-wise Average Player Points
6. Shooting Efficiency of Top Scorers
7. Correlation Heatmap of Performance Statistics
8. Variation in Points Scored by NBA Players

## How to Run

1. Install Python and Jupyter Notebook.
2. Install the required libraries:

   ```bash
   pip install pandas matplotlib seaborn
   ```

3. Open `Sports_Performance_Visualization.ipynb` in Jupyter Notebook.
4. Run the notebook cells from top to bottom.

An internet connection is required to load the dataset from its online CSV source.
